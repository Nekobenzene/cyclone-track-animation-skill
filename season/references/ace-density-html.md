# HTML 实时 ACE 密度预览

用 HTML 实时预览替代命令行交互。生成方式（从 skill 副本根目录运行）：

```text
python season/scripts/season_overview.py ace-html --season <project>
```

生成 `<project>/output/overview/ace_density_preview.html`，用现代桌面浏览器打开。
地图、当前季节数据、Saira 字体及 `ace_heat.png` 提取的 RGBA 色标均内嵌，
不需要安装 Python、运行命令或启动服务器来查看生成的页面。源数据更新后重新生成 HTML。

## 页面参数

| 参数 | 调节方式与作用 |
|---|---|
| 高斯 σ | 0.1–5°，数值或滑块，按地图像素密度换算核宽度，页面显示像素值 |
| 扩散半径 | 0.3–15°，每轴核截断范围，建议从 3σ 起步 |
| 路径步长 | 1–60 分钟，沿连续路径等时间分摊 |
| 标尺上限 | 默认全季峰值四舍五入到 0.01；手动输入也按 0.01 修约 |
| 不透明度 | 0–1，乘以素材原有 alpha |
| 计算精度 | 960×540、1280×720、1920×1080；精度越高计算越慢 |
| 导出尺寸 | 默认原地图精度（2020WP 为 8535×4800），也可选 1920×1080 或 3840×2160 |

图片使用素材的非线性色阶，但只放无刻度、无数字的色标柱；没有诊断标题。
页面控制区仍显示实际上限和峰值。上限按十进制四舍五入保留两位，最小 0.01。
超过上限的颜色饱和，实际密度不截断。图层顺序为地图 → 热力 → 纯色路径，路径位于最上方，不受热力调色。

正式批量出图先算全季峰值，作为全季和所有单旋的共享上限；单旋只用自身路径
独立计算热力，不从全季裁切，也不单独拉满色阶。见 [批量出图](ace-density.md)。
选定默认参数：σ=3°，半径=15°，步长=30 分钟，透明度=0.4，计算宽度=960。

## 连续显示与统计

TC-only 六小时 ACE 样本和总量计算不变。将每个有效贡献分摊到前后各三小时的
连续 TC 路径（在起止和变性边界截断并归一化），在像素浮点场中做双线性沉积。
随后进行每轴截断的可分离高斯卷积，再归一化保留窗口内贡献总量。经度在地图
中心附近展开；截图之外的样本不纳入可见密度，页面参数中分别记录全季和可见积分。

每个输出像素先插值**标量密度**，再映射 RGBA 色标；不是绘制彩色 1° 方格后
模糊图片。1° 网格保留用于原始统计，不再充当预览的显示像素。密度以
ACE/平方度表示，与 1°×1° 格的单位一致；不按实际地表面积换算，也不按海陆裁剪。

计算放在浏览器 Worker 中。σ、半径、路径步长或计算精度改变时重算；标尺和
不透明度改变仅重新着色。3D 风场或实际经过范围不应由平滑范围推断。

## 导出

“导出 PNG”保存当前视图；“保存参数”下载 JSON，记录 σ、半径、采样步长、
计算精度、标尺、透明度、实际峰值及 ACE 积分。通过 `--heat-parameters` 将 JSON 交给批量出图命令。
页面和参数都只属于工作副本的实验功能，不自动更新正式 skill。

内嵌地图按 EARTH 原图的 60 像素/度裁切，导出原地图精度时保留该取景的细节。

## 底片与内容

底片独立选择地图、黑底或透明底；内容独立选择路径＋热力、仅路径或仅热力。
PNG 导出保留透明底的 alpha；仅路径不导出热力或色标。两项选择同时保存进参数 JSON，
也可用 `--background map|black|transparent --layers both|track|heat` 初始化 HTML。
